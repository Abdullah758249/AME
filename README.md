# AME — موقع الشركة القابضة

موقع إنتاجي لشركة **AME** (مرحلة التأسيس) مع واجهة عامة ولوحة إدارة CMS كاملة وقاعدة بيانات حقيقية.

## المتطلبات

- Node.js 20+
- npm

## التثبيت والتشغيل

```bash
cd ame
npm install
npx prisma db push
npm run db:seed
npm run dev
```

> بعد تحديث المحرر: شغّل `npm install` مرة أخرى لتثبيت TipTap.

- **الموقع العام:** http://localhost:3000  
- **لوحة الإدارة:** http://localhost:3000/ame-admin

## ما يوفره المشروع

### الواجهة العامة

- الرئيسية، من نحن، الرؤية، الرسالة، القيم، الإدارة/القيادة
- الشركات التابعة، المشاريع، الأخبار (قوائم فارغة حتى تُضاف من CMS)
- صفحة لكل شركة/مشروع/خبر عند إنشائها
- صفحات CMS ديناميكية: `/pages/[slug]`
- تواصل (حفظ الرسائل في قاعدة البيانات)
- بحث حقيقي من API
- وضع ليلي/نهاري، عربي/إنجليزي، تصميم متجاوب

### محرر المحتوى (بدون كود)

- **محرر مرئي** للأخبار والصفحات والمشاريع والشركات التابعة والقيادة
- **صورة مميزة** منفصلة عن صور داخل النص (موضع أعلى الصفحة)
- **إدراج صور داخل المحتوى** حيث يقف المؤشر (محاذاة، عناوين، قوائم، روابط)
- **مكتبة وسائط**: رفع صور، PDF، Word، Excel، فيديو — ثم اختيار الملف من المكتبة
- لا تلصق مسار ملف من الجهاز (`C:\...` أو `file://`) — استخدم الرفع فقط

### لوحة الإدارة `/ame-admin`

- إعدادات الموقع والشعار واتصال
- القيادة، صفحات CMS، القوائم
- شركات تابعة، مشاريع، أخبار (CRUD كامل)
- رسائل التواصل، رفع وسائط
- إحصائيات زيارات **حقيقية فقط** (من جدول `PageVisit`)
- أمان: bcrypt، جلسات، CSRF، XSS (DOMPurify)، Prisma (SQL injection)
- 2FA (TOTP) اختياري
- سجل عمليات إدارية

### لا بيانات وهمية

- لا إحصائيات مُولَّدة
- لا شركات/مشاريع/أخبار افتراضية
- الأرقام في لوحة التحكم من قاعدة البيانات فقط

## الإنتاج

1. عيّن `SESSION_SECRET` عشوائيًا (32+ حرفًا).
2. استخدم PostgreSQL:

```env
DATABASE_URL="postgresql://user:pass@host:5432/ame"
```

غيّر في `prisma/schema.prisma`: `provider = "postgresql"`

3. `npx prisma migrate deploy`
4. `npm run build && npm run start`

على Vercel/Cloudflare: فعّل رأس الدولة (`cf-ipcountry` / `x-vercel-ip-country`) لإحصائيات الدول.
